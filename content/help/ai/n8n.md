## Что понадобится

Аккаунт n8n, подключённый сервис и общая ссылка из кабинета платформы. Авторизация: **Персональный ключ**.

Нужна версия n8n с поддержкой MCP Client. Возможности зависят от версии узла.

> Инструкция подготовлена по ТЗ. Перед публичным запуском её нужно сверить с актуальным интерфейсом клиента. Изображение — поясняющая схема, а не скриншот.

## 1. Скопируйте ссылку

В кабинете платформы подключите хотя бы один сервис. Откройте раздел подключения ИИ и скопируйте персональную ссылку. Адрес из примера не является рабочим сервером.

## 2. Добавьте подключение в n8n

Добавьте узел MCP Client. Выберите транспорт HTTP Streamable и вставьте адрес из кабинета.

![Схема: скопировать ссылку, добавить подключение в ИИ и подтвердить доступ](/img/help/ai-connect.svg)

## 3. Подтвердите доступ

Создайте credential с авторизацией Bearer и персональным ключом. Не записывайте ключ в обычное поле workflow.

Выдавайте доступ только выбранному вами клиенту. Не используйте чужие ссылки и никогда не публикуйте персональный ключ.

## 4. Проверьте результат

Откройте новый диалог и спросите: **«Покажи мои подключения»**. ИИ должен перечислить добавленные сервисы. Затем задайте небольшой вопрос по данным за конкретный день.

Если ответ содержит цифры, сверьте их с кабинетом сервиса: периоды, часовые пояса и статусы заказов влияют на итог.
